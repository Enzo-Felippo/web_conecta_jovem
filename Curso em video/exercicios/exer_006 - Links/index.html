Usando links externos

A tag <a> aceita os seguintes valores para o atributo target:

  • _blank: Abre o link em uma nova aba ou janela do navegador.
  • _parent: Abre o link no quadro ou frame pai (parent frame) da página atual. Se não houver frames, funciona como o _self.
  • _self: Abre o link na mesma aba e frame onde ele foi clicado (comportamento padrão).
  • _top: Abre o link no corpo completo da janela atual, cancelando todos os quadros (frames ou iframes) existentes.

O atributo rel

O atributo rel define a relação entre a página atual e o documento vinculado. Enquanto o target controla onde o link abre, o rel informa aos navegadores e buscadores (SEO) o que aquele link representa e como ele deve ser tratado.

Detalhes do parâmetro rel para links externos

Valor do rel Finalidade Segurança / Performance / SEO
external Sinaliza explicitamente que o link leva a um site externo ou domínio diferente. Informativo / SEO: Não altera o comportamento visual, mas ajuda mecanismos de busca e leitores de tela a identificar links externos.
noopener Impede que a nova página acesse o objeto window.opener da página de origem via JavaScript. Segurança crítica: Evita ataques do tipo Tabnabbing (onde a nova aba pode redirecionar a sua página original para um site malicioso). Nota: Navegadores modernos aplicam isso automaticamente ao usar target="_blank", mas mantê-lo é uma boa prática.
noreferrer Bloqueia o envio do cabeçalho HTTP Referer para o site de destino. Privacidade & Segurança: O site de destino não saberá de qual URL exata o usuário veio. Também inclui o comportamento do noopener.
nofollow Orienta os motores de busca (Google, Bing) a não transferir autoridade/relevância de SEO para o link. SEO: Ideal para links patrocinados, de afiliados ou conteúdo não verificado.
