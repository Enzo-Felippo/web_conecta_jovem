🏗️ Estrutura semântica

Elementos utilizados para organizar as grandes partes de uma página HTML.

ESTRUTURA

<header>

Define um cabeçalho. O conteúdo dentro dele pode representar informações introdutórias ou de navegação relacionadas à página ou a uma seção.

VISUALIZAÇÃO

Meu site

Bem-vindo ao meu conteúdo.

<header>
  <h1>Meu site</h1>
  <p>Bem-vindo ao meu conteúdo.</p>
</header>
SEMÂNTICA

<nav>

Representa uma seção de navegação. É muito utilizada para menus e conjuntos de links importantes.

VISUALIZAÇÃO
🏠 Início | 📚 Cursos | 📞 Contato 
<nav>
  <a href="#">Início</a>
  <a href="#">Cursos</a>
  <a href="#">Contato</a>
</nav>
ESTRUTURA

<main>

Representa o conteúdo principal da página. Deve conter aquilo que está diretamente relacionado ao objetivo central daquele documento. 

<main>
  Conteúdo principal da página
</main>
ESTRUTURA

<footer>

Representa o rodapé de uma página ou seção. É comum encontrar informações como direitos autorais, contatos e links adicionais. 

<footer>
  <p>© 2026 Meu Site</p>
</footer>

✍️ Formatação semântica de texto

Algumas tags não servem apenas para mudar a aparência: elas dão significado ao texto.

SEMÂNTICA

<strong>

Indica que determinado trecho possui forte importância, seriedade ou urgência.

RESULTADO
Este é um texto importante. 
<strong>texto importante</strong>
NÃO SEMÂNTICA

<b>

Aplica destaque visual em negrito, mas não adiciona significado semântico de importância.

RESULTADO
Este é um texto em negrito. 
<b>texto em negrito</b>
SEMÂNTICA

<em>

Representa ênfase em determinado trecho.

RESULTADO
Isso é muito importante. 
<em>muito importante</em>
NÃO SEMÂNTICA

<i>

Representa uma mudança de voz ou um texto que deve ser visualmente diferenciado, sem necessariamente indicar ênfase.

RESULTADO
Termo estrangeiro 
<i>Termo estrangeiro</i>
SEMÂNTICA

<ins>

Representa um trecho que foi inserido no documento.

RESULTADO
Este texto foi adicionado posteriormente. 
<ins>adicionado posteriormente</ins>
NÃO SEMÂNTICA

<u>

Representa uma anotação ou destaque visual sublinhado. Não deve ser usado simplesmente como substituto de estilos quando CSS é apropriado.

RESULTADO
Texto sublinhado 
<u>Texto sublinhado</u>
SEMÂNTICA

<mark>

Destaca um trecho por sua relevância dentro do contexto.

RESULTADO
Este trecho é relevante para o assunto. 
<mark>relevante para o assunto</mark>
SEMÂNTICA

<del>

Indica que determinado conteúdo foi removido ou considerado excluído.

RESULTADO
Preço: R$ 100 R$ 80 
<del>R$ 100</del> R$ 80
SEMÂNTICA

<small>

Representa observações, comentários, avisos legais, direitos autorais ou informações secundárias.

RESULTADO
© 2026 — Todos os direitos reservados. 
<small>
  © 2026 — Todos os direitos reservados.
</small>
SEMÂNTICA

<sup>

Exibe um conteúdo em posição superior à linha normal. É útil para expoentes e referências.

RESULTADO
x20 + 3
x<sup>20</sup> + 3
SEMÂNTICA

<sub>

Exibe um conteúdo abaixo da linha normal. É bastante utilizado em fórmulas químicas.

RESULTADO
H2O
H<sub>2</sub>O

🧩 Seções de conteúdo

Elementos que ajudam a dividir semanticamente diferentes partes do documento.

SEMÂNTICA

<section>

Representa uma seção temática do conteúdo. Normalmente possui um título próprio. 

<section>

  <h2>Meus estudos</h2>

  <p>
    Conteúdo sobre programação.
  </p>

</section>
SEMÂNTICA

<article>

Representa um conteúdo independente, que poderia ser distribuído ou reutilizado separadamente. É comum em posts, notícias e artigos. 

<article>

  <h2>Aprendendo HTML</h2>

  <p>
    HTML define a estrutura das páginas.
  </p>

</article>
SEMÂNTICA

<aside>

Representa conteúdo relacionado de forma indireta ao conteúdo principal.

EXEMPLO
💡 Curiosidade:

HTML significa HyperText Markup Language.

<aside>
  <strong>Curiosidade:</strong>
  <p>HTML significa HyperText Markup Language.</p>
</aside>

📦 Containers: div e span

Elementos genéricos utilizados principalmente para agrupar conteúdo.

NÃO SEMÂNTICA

<div>

É um container genérico para conteúdo de fluxo. Não possui significado semântico próprio e é muito utilizado para organização e estilização com CSS.

EXEMPLO
Grupo de conteúdo

Estes elementos estão agrupados dentro de uma div.

<div>

  <strong>Grupo de conteúdo</strong>

  <p>
    Estes elementos estão agrupados.
  </p>

</div>
NÃO SEMÂNTICA

<span>

É um container genérico para conteúdo em linha. É útil para selecionar pequenos trechos de texto e aplicar estilos ou comportamentos.

EXEMPLO
Aprender HTML é aprender a estruturar documentos. 
Aprender
<span>HTML</span>
é aprender a estruturar documentos.

💻 Texto pré-formatado

Elemento especialmente interessante para representar textos nos quais espaços e quebras de linha devem ser preservados.

PRÉ-FORMATADO

<pre>

Preserva espaços e quebras de linha do conteúdo. É muito utilizado para exibir código e textos pré-formatados.

RESULTADO
print("Hello World!")

nome = "Enzo"

print(nome)
<pre>
print("Hello World!")

nome = "Enzo"

print(nome)
</pre>

🛠️ Outras formatações

Elementos utilizados para representar código, citações e abreviações de maneira semântica.

SEMÂNTICA

<code>

A tag <code> representa um trecho de código de computador. Por padrão, o navegador utiliza uma fonte monoespaçada.

RESULTADO
Execute print("Hello World!") no Python. 
<code>print("Hello World!")</code>
SEMÂNTICA

<pre> + <code>

A combinação de <pre> com <code> é muito utilizada para representar blocos de código. O <pre> preserva os espaços e as quebras de linha, enquanto o <code> identifica o conteúdo como código.

RESULTADO 
nome = input("Digite seu nome: ")

print(f"Olá {nome}")
<pre>
  <code>
nome = input("Digite seu nome: ")
print(f"Olá {nome}")
  </code>
</pre>

💡 Resumo: <code> identifica código; <pre> preserva a formatação original.

SEMÂNTICA

<q>

A tag <q> representa uma citação curta que faz parte de um parágrafo. Os navegadores normalmente adicionam aspas automaticamente.

RESULTADO
Como diria o Chaves: Prefiro morrer do que perder a vida. 
<p>
  Como diria o Chaves:
  <q>Prefiro morrer do que perder a vida.</q>
</p>
SEMÂNTICA

<blockquote>

Representa uma citação longa ou um trecho de outro documento. Diferentemente de <q>, normalmente ocupa um bloco próprio.

RESULTADO

Segundo Jeff Noble, no seu livro HTML para Leigos:

A diferença entre elementos inline e um bloco de texto é importante. Os elementos HTML nesse capítulo descrevem os blocos de texto. 
<p>
  Segundo Jeff Noble, no seu livro
  HTML para Leigos:
</p>

<blockquote cite="URL">
  A diferença entre elementos inline e um
  bloco de texto é importante.
</blockquote>

🔗 O atributo cite pode indicar a fonte ou URL de onde a citação foi retirada.

SEMÂNTICA

<abbr>

Representa uma abreviação ou sigla. O atributo title pode fornecer a forma completa ou uma explicação.

PASSE O MOUSE SOBRE AS SIGLAS
Estou estudando HTML e CSS. Estou adorando! 
<p>

  Estou estudando
  <abbr title="HyperText Markup Language">
    HTML
  </abbr>

  e

  <abbr title="Cascading Style Sheets">
    CSS
  </abbr>.

</p>

💡 Detalhe interessante: ao passar o mouse sobre HTML ou CSS, o navegador pode mostrar o conteúdo do atributo title.

📋 Listas

HTML possui elementos específicos para representar listas ordenadas e não ordenadas.

<ol> — Lista ordenada

Utilizada quando a ordem dos itens possui significado.

Resultado:
  1. Estudar HTML
  2. Estudar CSS
  3. Estudar JavaScript
<ol>

  <li>Estudar HTML</li>
  <li>Estudar CSS</li>
  <li>Estudar JavaScript</li>

</ol>

<ul> — Lista não ordenada

Utilizada quando a ordem dos itens não possui significado específico.

Resultado:
  • HTML
  • CSS
  • JavaScript
<ul>

  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>

</ul>

<footer>

O rodapé normalmente contém informações complementares sobre o documento ou seção.

Exemplo de endereço: Rua 25, Pedra 90 — Cuiabá - MT
