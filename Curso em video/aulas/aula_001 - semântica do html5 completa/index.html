🧱 Semântica do HTML5

HTML5 foca em significado, e não apenas na aparência do conteúdo. As tags semânticas ajudam o navegador, mecanismos de busca e tecnologias assistivas a entender a função de cada parte da página.

<header>

Define um cabeçalho. O conteúdo dentro dele faz parte do cabeçalho de uma página ou seção.

<header>
  <h1>Título da página</h1>
</header>

<nav>

Representa uma área de navegação. É muito utilizada para menus e conjuntos de links.

  • Ir para listas
  • Ir para formatação

<main>

Representa o conteúdo principal da página, relacionado diretamente ao tópico central ou à funcionalidade principal do documento.

<section>

Representa uma seção temática da página.

<article>

Representa um conteúdo independente, como um artigo, postagem de blog ou notícia.

<aside>

Representa um conteúdo relacionado indiretamente ao conteúdo principal, como uma barra lateral, informações complementares ou observações.

<div>

É um container genérico sem significado semântico próprio. É muito utilizado para organizar elementos e aplicar estilos.

💡 Use elementos semânticos quando eles representarem corretamente o conteúdo. Use <div> quando não existir um elemento semântico apropriado.

<span>

É um container genérico inline, normalmente utilizado para estilizar ou identificar pequenos trechos de texto.

Exemplo: este trecho está dentro de um span.

<footer>

Define um rodapé para uma página ou seção.

<address>

Representa informações de contato relacionadas ao conteúdo ou responsável pela página.

✏️ Formatação de textos

HTML5 possui elementos que permitem indicar diferentes significados para trechos de texto.

<strong> — importância

Indica que determinado conteúdo possui forte importância.

É uma tag semântica.

<b> — destaque visual

Produz um destaque visual em negrito, mas sem indicar importância semântica.

É uma tag não semântica.

<em> — ênfase

Indica ênfase no conteúdo: este trecho possui ênfase.

<i> — destaque visual em itálico

Produz visualmente itálico, sem necessariamente representar ênfase.

<ins> — conteúdo inserido

Indica conteúdo que foi inserido no documento.

<u> — destaque visual

Produz visualmente um sublinhado.

<mark> — destaque contextual

A tag <mark> indica um trecho destacado por sua relevância contextual.

<del> — conteúdo removido

Indica conteúdo que foi removido ou marcado como excluído.

<small> — informação secundária

Representa informações secundárias, como observações, avisos legais ou direitos autorais.

Este é um exemplo de texto secundário.

<sup> — sobrescrito

Utilizado para conteúdos que aparecem acima da linha normal do texto.

Exemplo: x20 + 3

<sub> — subscrito

Utilizado para conteúdos que aparecem abaixo da linha normal do texto.

Exemplo: H2O

<pre> — texto pré-formatado

Mantém espaços e quebras de linha do conteúdo original. É bastante utilizado junto com <code> para apresentar códigos. 

print("Hello World!")

🔗 Links externos

A tag <a> é utilizada para criar hyperlinks.

O atributo target

O atributo target determina onde o link será aberto.

  • _blank: abre o link em uma nova aba ou janela.
  • _self: abre o link no contexto atual. É o comportamento padrão.
  • _parent: abre o link no contexto pai.
  • _top: abre o link no contexto completo da janela.

O atributo rel

O atributo rel define a relação entre a página atual e o documento vinculado.

Enquanto target controla onde o link será aberto, rel fornece informações sobre a relação e o tratamento do link.

Valor Finalidade Observação
external Indica que o link aponta para um recurso externo. É principalmente uma informação semântica.
noopener Impede o acesso da nova página ao window.opener. Relacionado à segurança ao utilizar target="_blank".
noreferrer Impede o envio do cabeçalho HTTP Referer. Aumenta a privacidade da navegação e também implica o comportamento de noopener.
nofollow Indica aos mecanismos de busca que o link não deve ser tratado como uma recomendação normal. É especialmente usado em situações relacionadas a SEO, publicidade ou conteúdo não confiável.
